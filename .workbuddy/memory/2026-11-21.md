## 应用图标重绘 + Finder/Dock 显示中文名（同日）

- **新图标「宝丽来 · 黄昏」**：暖石墨圆角底（ink-900/800/600）+ 相纸白边框（paper）+ 框内落日光晕（safelight #e8a33d）。配色全部取自 `src/styles/styles.css` 的暗房色板，不再用外观来源不明的旧图。
- **图标改为矢量单一源**：`build/icon-source.svg`（1024×1024，主体 824、圆角 185、四周 100 透明边距，符合 macOS 图标规格）→ `npm run icon:build`（`build/make-icon.cjs`，依赖 `rsvg-convert` + `iconutil`）→ `build/icon.icns`。不要手改 icns。
- **中文显示名的正确做法**：`package.json` 的 `mac.extendInfo` 写 `CFBundleDisplayName` / `CFBundleName` = 时光画框；`productName` / `appId` / `.app` 文件名 / DMG 文件名保持 PhotoMinder（更新清单与升级身份依赖它）。
- **踩到的坑（重要）**：`CFBundleDisplayName` 变中文会让 Electron 的 `app.name` 跟着变，`userData` 默认迁到 `Application Support/时光画框/`，老数据全失联。解法是 `electron/main.js` 在**第一次 `getPath('userData')` 之前**显式 `app.setPath('userData', join(getPath('appData'), 'PhotoMinder'))`。APFS 默认大小写不敏感，能命中既有的 `photominder/` 目录。
- 连带改动：`tests/main-process/harness.cjs` 的 electron 桩补 `setPath` 并让 `getPath('appData')` 返回独立临时目录（userData 初值与钉死目标同名，setPath 幂等）；`tests/unit/branding.test.ts` 新增 3 条断言（extendInfo 中文名 / setPath 位置在首次 getPath 之前 / 图标单一源）；`eslint.config.mjs` 的 build 匹配从 `build/**/*.js` 扩到 `*.{js,cjs}`；ADR-002、AGENTS.md §4.3、CHANGELOG [Unreleased] 同步。
- **本机打包环境的坑**：沙箱的 `NODE_OPTIONS` 注入了 fs shim（`node-language-shim.cjs`），会让 electron-builder 复制 Electron.app 时抛 `ENOENT`；electron-builder 直连下载 Electron 会 502。可行路径：`NODE_OPTIONS= npx electron-builder --mac --arm64 -c.electronDist=<解压后的 Electron.app 目录>`，缓存 zip 在 `~/Library/Caches/electron/*/electron-v44.10.2-darwin-arm64.zip`。另外 `release/mac-arm64` 若已存在，safe-delete 守卫会拦 rm，先 `mv` 到 /tmp。
- 验证：`npm run verify` 全绿（28 文件 431 项）；打包产物 Info.plist 的 `CFBundleDisplayName` / `CFBundleName` 均为「时光画框」，`CFBundleIdentifier` 仍 `com.photominder.app`；DMG 92.8MB（ULMO 后 88.5MB）。
