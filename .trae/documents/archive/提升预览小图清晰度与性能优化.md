# 提升预览小图清晰度与性能优化

## 问题分析
1. **当前预览小图机制**：
   - `createThumbnail` 函数生成的缩略图最大尺寸为 400px
   - 图片网格使用 `photo.thumbnail || photo.url` 显示图片
   - 缩略图存储在 `photo.thumbnail` 属性中

2. **存在的问题**：
   - 预览小图质量不够高，放大时会模糊
   - 大量图片加载时可能导致性能问题

## 优化方案

### 1. 提高缩略图清晰度

**修改 `App.tsx` 中的 `createThumbnail` 函数**：
- 增加缩略图最大尺寸到 800px
- 提高 JPEG 压缩质量到 0.95
- 优化 Canvas 渲染质量

### 2. 实现智能图片加载策略

**优化 `ImageCard` 组件**：
- 实现可见性检测，只加载视口内的图片
- 增加图片加载优先级，优先加载当前可见区域的图片
- 实现图片加载节流，避免同时加载太多图片

### 3. 优化图片缓存机制

**改进 `App.tsx` 中的图片处理逻辑**：
- 实现缩略图缓存，避免重复生成
- 为不同缩放级别生成不同尺寸的缩略图
- 实现图片懒加载，只在需要时生成缩略图

### 4. 优化网格渲染性能

**改进 `ImageGrid` 组件**：
- 实现虚拟滚动，只渲染可见区域的图片
- 优化 CSS 布局，减少重排重绘
- 实现图片加载状态的平滑过渡

## 实施步骤

1. **修改 `createThumbnail` 函数**，提高缩略图质量
2. **优化 `ImageCard` 组件**，实现可见性检测和智能加载
3. **改进图片缓存机制**，实现多级缓存
4. **优化 `ImageGrid` 组件**，实现虚拟滚动
5. **测试性能**，确保优化效果符合预期

## 预期效果

- 预览小图清晰度提高，放大查看时不再模糊
- 大量图片加载时应用保持流畅
- 内存占用降低，避免应用崩溃
- 图片加载速度更快，用户体验提升

## 技术要点

- 使用 Intersection Observer API 实现可见性检测
- 优化 Canvas 渲染参数
- 实现多级缩略图缓存
- 实现虚拟滚动技术
- 优化图片加载优先级
